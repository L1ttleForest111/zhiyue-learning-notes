# 学习计划

记录阶段目标、任务编号、完成标准和产出链接。计划只回答“学什么、做到什么程度”，具体知识归入主题笔记，真实项目实践归入案例。

## 使用约定

1. 使用稳定任务编号，例如 `P0-01`，方便 Canvas、主题笔记和项目案例互相引用。
2. Canvas 用于日常推进和勾选，Markdown 计划是长期准本。
3. 完成任务时附上主题笔记、项目案例或可验证结果，不只修改复选框。
4. 不在计划中堆放大段概念说明；概念应整理到对应知识分类。
