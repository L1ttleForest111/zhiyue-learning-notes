# 项目实践案例

记录在真实项目中完成的分析、改动、验证和结果，用来证明知识已经应用，而不只是阅读过概念。

## 项目

- [`agentic-mall`](./agentic-mall/README.md)：运营端、小程序、Buddy / AI 助手相关实践。

## 案例完成标准

一篇案例至少说明：

1. 背景与用户可感知的问题；
2. 自己承担的任务和边界；
3. 关键代码路径与完整数据流；
4. 方案选择及没有采用其他方案的原因；
5. 验证方式、前后对比和可量化结果；
6. 遗留问题，以及可用于面试表达的 STAR 摘要。

新建案例时使用 [`project-case-template.md`](../templates/project-case-template.md)。
